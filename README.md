# 🏠 Home Automation System – IoT Project

## 📌 Project Overview

The **Home Automation System** is an IoT-based project developed as part of an internship at **Emertxe Information Technologies**. The project focuses on controlling and monitoring home appliances using a microcontroller-based system.

## 🎯 Objectives

- Develop a basic IoT-based home automation system.
- Control home appliances electronically.
- Understand microcontroller-based system design.
- Apply C programming concepts to embedded applications.
- Gain practical experience in IoT and embedded systems.

## 🛠️ Technologies Used

- C Programming
- Microcontroller
- IoT
- Embedded Systems
- Electronic Components
- Hardware Interfacing

## ⚙️ Working Principle

The system uses a microcontroller to receive user commands and control connected home appliances. Based on the input, the microcontroller operates the corresponding devices, enabling convenient and automated control.
